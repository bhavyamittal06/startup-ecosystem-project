How data flows through the platform
User opens browser → hits Frontend
Frontend sends API request → Backend processes it
Backend applies business logic via Core Modules
Backend reads/writes from Database
Backend calls External Services when needed
The platform has 6 distinct user roles, each with different access levels, dashboards, and permissions.
🚀
Startup Founder
The core user — applies for funding and pitches ideas
LIMITED ACCESS
Register startup & build public profile
Submit pitch deck for evaluation
Track pitch status & investor interest
View funding history & received investments
Book mentorship sessions
Register for pitching events
View own analytics (views, pitch scores)
✗Cannot see other startups' private data or investor details
💰
Investor
Reviews startups and manages their investment portfolio
ELEVATED ACCESS
Browse all startup profiles & pitch decks
View full pitch submissions & financials
Record investment interest & deal notes
Track portfolio of funded startups
Attend & evaluate at pitching events
Message startups directly
View investment analytics & ROI tracking
✗Cannot manage events or modify platform settings
🧠
Mentor
Industry expert who guides startups through their journey
STANDARD ACCESS
Create public mentor profile with expertise
Accept or decline mentorship requests
Schedule 1-on-1 sessions with startups
Add notes & progress reports per startup
View assigned startups' profiles & pitches
Participate in events as a resource person
✗Cannot invest, score pitches, or manage events
⚖️
Jury Member
Evaluates startups at Shark Tank-style pitching events
EVENT ACCESS
Access assigned event's pitch list
View startup profiles & submitted decks
Score pitches using evaluation rubric
Add qualitative feedback per startup
View live leaderboard during event
Submit final verdict & recommendation
✗Cannot see other jury scores until event ends. Cannot invest.
📅
Event Manager
Organises and manages all pitching events on the platform
OPERATIONAL ACCESS
Create & publish pitching events
Assign jury members to events
Manage startup registrations per event
Set pitch schedule & time slots
Send bulk notifications to participants
View live evaluation progress during event
Export event summary & results report
✗Cannot modify user accounts or platform-wide settings
🛡
Admin
Full control over the entire platform and all users
FULL ACCESS
Create, edit, delete any user account
Assign & change user roles
Approve / reject startup registrations
Manage all platform content & data
View full analytics across all users
Configure platform settings
Export data & generate reports
★ Superuser — no restrictions on the platform
